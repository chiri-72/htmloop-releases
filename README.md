# HTMLoop releases

Release assets for the HTMLoop macOS app (Apple Silicon): the installer DMG, the in-app updater bundle (`HTMLoop.app.tar.gz` + `.sig`) and the updater manifest (`latest.json`).

- The app checks `https://github.com/chiri-72/htmloop-releases/releases/latest/download/latest.json` for updates and verifies every update with the HTMLoop update signing key before installing it.
- Releases marked **pre-release** are internal test builds and are never offered to users automatically.
- Source code is not published here. Support: choel6721@gmail.com, or Help › Report a Problem in the app.
